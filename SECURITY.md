# Security Policy

## Supported Versions

The following table indicates which versions of PlaxionMediator are currently receiving security updates.

| Version | Supported |
| ------- | :-------: |
| Latest stable | ✅ |
| Older versions | ❌ |

Only the latest stable release receives security fixes. Users are encouraged to upgrade to the most recent version.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in PlaxionMediator, please report it responsibly.

### How to report

Please open a **private security advisory** through GitHub if available. If that is not possible, contact the maintainer directly instead of creating a public issue.

When reporting a vulnerability, please include:

- A clear description of the issue.
- Steps to reproduce the vulnerability.
- The affected version(s).
- Any proof-of-concept code or screenshots, if applicable.
- Your assessment of the potential impact.

### What to expect

After receiving your report:

- We will acknowledge receipt as soon as reasonably possible.
- We will investigate the issue and determine its severity.
- If the report is confirmed, a fix will be developed and released in a future version.
- If the report is not considered a security vulnerability, we will explain the reasoning whenever possible.

We kindly ask that you avoid publicly disclosing the vulnerability until a fix has been released.
