# PlaxionMediator Wiki

Welcome to the **PlaxionMediator** wiki. PlaxionMediator is a Native AOT-safe, zero-reflection, source-generator-first request/response and notification pipeline for .NET — a from-scratch request pipeline platform for developers.

> These pages live under [`docs/wiki`](https://github.com/avmp2208/PlaxionMediator/tree/master/docs/wiki) in the main repository and are mirrored into this GitHub Wiki so they stay versioned alongside the code. To update the wiki, edit the markdown files in `docs/wiki` and copy them into the Wiki tab (or sync via the wiki git remote).
